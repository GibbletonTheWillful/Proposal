## In just a sentence or two, summarize your project. (E.g., "A website that lets you buy and sell stocks.")

My project is a Python application that generates and sends realistic simulated phishing emails using SMTP email services. After the recipient interacts with the email, the program will explain common phishing tactics and warning signs through an educational interface.

## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

OwlSecure is a Python program that demonstrates how phishing emails can be used to trick people and teaches users how to recognize them. The program will create and send simulated phishing emails to a chosen email address using SMTP. These emails will be based on common university scams, such as account verification requests, scholarship offers, or account suspension notices. After interacting with the email, the user will see a screen explaining the red flags in the message, such as urgent language, suspicious senders, and requests for login information. The program will not collect or save any credentials. The project will use Python features such as functions, conditionals, string manipulation, randomization, and email automation.
